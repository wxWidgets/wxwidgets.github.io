This is [another][last] combined announcement for the latest stable and
development releases that were both made available today. As before, 3.3.4
contains all the changes from 3.2.12 as well as improvements specific to the
development branch, such as yet more fixes for wxMSW dark mode support and
improved support for Wayland in wxGTK.

Both releases can be downloaded from GitHub, please follow these links to
download archives with the library sources and documentation as well as
binaries for the selected Windows compilers such as [Microsoft Visual
C++][msvc] and [MinGW-w64][mingw64]: for [3.2.12 release][3.2.12-release] and
for [3.3.4 one][3.3.4-release]. Online documentation has also been updated and
can be accessed at [3.2.12 documentation home][3.2.12-docs] and
[3.3.4][3.3.4-docs] respectively.

### Call for testing

We hope that 3.3.4 will be the last development release before releasing 3.4.0,
the beginning of the next stable releases series. Because of this, bug reports
and especially regressions for 3.3.4 would be even more welcome than usual:
please try using this wxWidgets version in your applications and let us know
about any problems so that we could fix them before 3.4.0. Thanks in advance!


### Changes since previous releases

3.3.4 contains about 900 commits from 52 unique contributors done during the
last 3 months. The amount of changes is too big to list them all here, but most
of them fall into the following categories:

- Numerous bug fixes and improvements for wxMSW dark mode.
- Better Wayland support in wxGTK, notably implementing wxAUI panes dragging
  and restoring top level windows positions (when the required protocols are
  available). `wxTaskBarIcon` also works under Wayland now (with AppIndicator).
- Improved accessibility support on all platforms, including wxOSX and wxGTK.
- Improved handling of IME under all platforms.
- Several major new features added to `wxRibbonControl`.
- Some long standing bugs in (TCP-based) wxIPC and `wxSocket` have been fixed.
- Accelerator key handling has been made more flexible and consistent.

As usual, more details can be found in the change log [for 3.3.4][changes-3.3.4]
and [for 3.2.12][changes-3.2.12].
